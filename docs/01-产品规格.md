> 版本：v0.1（待评审）

---

## 1. 产品定位

ReedShell 是一款用 Rust 编写的跨平台 SSH 客户端，面向开发者与运维人员，提供终端、SFTP、端口转发、跳板机等完整能力，并通过端到端加密在多个设备之间同步连接、密钥与偏好设置。

- **主打个人工具**：首期不做组织、成员、RBAC、共享连接。
- **本地优先**：所有功能在离线状态下可用；同步是增值能力，不是使用前提。
- **零知识服务端**：服务端只保存密文与同步所需的元数据，无法解密用户的连接信息与凭据。
- **原生多端**：桌面端 Iced，移动端 Slint，不使用 WebView 承载主界面。

### 1.1 目标用户

| 用户 | 场景 | 核心诉求 |
|---|---|---|
| 个人开发者 | 管理 5~50 台服务器 | 连接管理、多标签、SFTP、配置不丢 |
| 运维/SRE | 跳板机、批量操作、端口转发 | 跳板链、隧道、稳定长连接 |
| 多设备用户 | 公司电脑 + 家用电脑 + 手机 | 连接信息与密钥自动同步、随时应急 |

### 1.2 商业模型

| 版本 | 能力 | 价格 |
|---|---|---|
| Free（本地版） | 全部本地功能：连接管理、终端、SFTP、端口转发、跳板机，无设备数量限制，无需注册 | 免费 |
| Pro（云同步版） | Free 全部能力 + 端到端加密云同步 + 设备管理 + 恢复码 + 多端（含移动端） | ¥6/月、¥60/年 |

- Free 用户不注册、不联网即可使用全部本地功能。
- Pro 才需要账号；订阅到期后进入宽限期，只读同步，本地功能不受影响。
- 首期支付渠道：易支付 V1 接口（聚合收银台，下单时不传 `type` 字段）+ 管理员生成的兑换码。
- 定价：月付 ¥6（600 分）、年付 ¥60（6000 分）；价格存后台配置，不硬编码。
- 试用：注册后可领取 14 天 Pro 试用（每个账号一次）。

## 4. 首期明确不做（Non-Goals）

- 团队/组织、成员邀请、RBAC、共享连接、操作审计。
- Web 端 SSH / 终端（明确不做）。
- 会话录制与回放（v2 候选）。
- Mosh、X11 转发、ZMODEM、串口。
- 插件系统、脚本/自动化 API、AI 助手。
- Linux 桌面官方支持（代码可编译，但不承诺打包与测试）。
- 同步终端历史、滚动缓冲、文件传输记录。

## 5. 验收标准（摘要）

| 模块 | 可验收标准 |
|---|---|
| 连接 | 导入 100 条 `ssh_config` 无丢失；重命名/分组后重启保持一致；搜索 200 条连接结果 < 100ms |
| 认证 | 密码、Ed25519、RSA-4096、带口令私钥、PPK、Agent、keyboard-interactive 全部可登录真实主机；2FA 可输入 |
| 终端 | 通过 vttest 核心用例；`vim`、`tmux`、`htop`、`top`、`less` 无错位；CJK 与 emoji 宽度正确；60fps 滚动 10,000 行不卡顿 |
| 会话 | 50 标签稳定运行 8 小时，内存增长 < 20%；断网 30 秒后自动重连成功并提示 |
| SFTP | 传输 1GB 单文件成功；断点续传从 60% 恢复；100 个并发队列稳定；中文文件名正常 |
| 转发 | `-L`/`-R`/`-D` 均可用浏览器/curl 验证；SOCKS5 支持 IPv4/IPv6/域名 |
| 跳板 | 3 级跳板链登录成功；中间跳板失败时提示具体跳数 |
| 安全 | 本地库无明文密码/私钥；主机指纹变更被阻断；服务端数据库中无可解密字段 |

## 7. 术语

| 术语 | 含义 |
|---|---|
| 主密钥 MK | 32 字节随机密钥，所有同步数据加密的根，永不上传 |
| KEK | 由用户密码派生的密钥加密密钥，仅用于包裹 MK |
| 设备密钥 | 每台设备本地生成，存于系统安全存储，用于设备绑定与本地解锁 |
| 恢复码 | MK 的另一种包裹形式，用于密码与设备全部丢失时恢复 |
| HLC | 混合逻辑时钟，用于跨设备冲突判定 |
| 墓碑 | 标记已删除的记录，用于把删除操作同步给其他设备 |
