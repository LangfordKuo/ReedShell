# 交互与 UI 规范

> 版本：v0.1（待评审）
> 设计语言：Fluent 2（桌面）、Material 风格简化（移动）、shadcn/ui 默认（Web）

---

## 1. 设计原则

1. **工具优先**：界面为高频操作让路，默认布局下终端占据最大面积。
2. **本地优先**：无网络、未登录时不出现阻塞式登录墙；同步状态永远是非阻塞提示。
3. **危险操作可逆**：删除、广播输入、覆盖主机指纹等提供确认或回收站。
4. **状态可见**：连接状态、同步状态、传输进度始终在固定位置可见。
5. **跨端一致**：同一业务概念使用同一名称、同一图标语义、同一错误文案。

## 2. 设计令牌（Token）

### 2.1 颜色

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `bg` | `#F3F3F3` | `#1F1F1F` | 窗口背景 |
| `surface` | `#FFFFFF` | `#282828` | 面板、卡片 |
| `surface-alt` | `#FAFAFA` | `#2D2D2D` | 悬停、次级面板 |
| `stroke` | `#E5E5E5` | `#3D3D3D` | 边框、分隔线 |
| `text` | `#1A1A1A` | `#FFFFFF` | 主文本 |
| `text-secondary` | `#5C5C5C` | `#C7C7C7` | 次要文本 |
| `text-tertiary` | `#8A8A8A` | `#9A9A9A` | 占位、禁用 |
| `accent` | `#0F6CBD` | `#479EF5` | 主按钮、选中 |
| `accent-hover` | `#115EA3` | `#62ABF5` | |
| `success` | `#0F7B0F` | `#6CCB5F` | 已连接 |
| `warning` | `#9D5D00` | `#FCE100` | 重连中、到期 |
| `danger` | `#C42B1C` | `#FF99A4` | 断开、删除 |
| `overlay` | `rgba(0,0,0,.4)` | `rgba(0,0,0,.6)` | 模态遮罩 |

- 全部颜色以 CSS 变量 / Rust 常量双份维护，禁止散落硬编码。
- 对比度：正文 ≥ 4.5:1，大字号 ≥ 3:1。

### 2.2 字体

| 用途 | 字体栈 |
|---|---|
| UI（Win） | `Segoe UI Variable Text`, `Segoe UI`, `Inter`, sans-serif |
| UI（macOS） | `SF Pro Text`, `Inter`, sans-serif |
| 等宽（终端） | `Cascadia Mono`, `JetBrains Mono`, `Menlo`, `Consolas`, monospace |
| CJK 回退 | `Noto Sans SC` / `Sarasa Mono SC`（终端等宽 CJK） |

- 字号：11 / 12 / 14（默认）/ 16 / 20 / 28。
- 行高：UI 1.4；终端默认 1.25（可调 0.9–1.6）。
- 终端字体默认 13px（桌面）/ 12px（移动），支持 8–32px。

### 2.3 间距、圆角、阴影

- 间距：4 / 8 / 12 / 16 / 24 / 32（4px 基准）。
- 圆角：小 4、中 8、大 12；输入框与按钮统一 4。
- 阴影：仅浮层使用 `0 8px 24px rgba(0,0,0,.14)`；面板用 1px 边框，不用阴影。

### 2.4 动效

- 时长：快 100ms（悬停）、中 180ms（面板展开）、慢 260ms（页面切换）。
- 缓动：`cubic-bezier(.2,0,0,1)`。
- 尊重系统"减少动态效果"设置。

│ ───────────── ├─────────────────────────────────────────────────────────────┤
│ ▾ 生产环境  ⭐ │                                                             │
│   ● web-01    │                                                             │
│   ● db-01     │                       终 端 区 域                            │
│   ○ cache-01  │                                                             │
│ ▾ 测试环境    │                                                             │
│   ○ test-01   │                                                             │
│               │                                                             │
│ ───────────── │                                                             │
│ + 新建连接    ├─────────────────────────────────────────────────────────────┤

```

| 区域 | 规格 |
|---|---|
| 标题栏 | 32px，自绘，可拖动；显示同步状态点（灰=未登录，绿=已同步，蓝=同步中，橙=离线/冲突） |
| 侧栏 | 默认 260px，范围 200–420px；可折叠（`Ctrl+B`） |
| 标签栏 | 36px，支持滚轮横向滚动；标签最大 200px，超出省略 |
| 状态栏 | 24px，左：延迟/加密算法/终端尺寸/编码；右：同步状态与待办数 |

### 3.2 连接侧栏

- 顶部搜索框，匹配名称、主机、标签、备注；输入时实时过滤。
- 分组可折叠；拖拽连接改变分组或顺序；右键菜单：连接、编辑、复制、SFTP、转发、删除。
- 状态点：灰=未连接，绿=已连接，黄=重连中，红=失败。
- 底部固定："新建连接"与"设置"。
- 空状态：插画 + "还没有连接" + 主按钮"新建连接" + 次按钮"导入 ssh config"。

### 3.3 标签

- 内容：状态点 + 名称 + 关闭按钮；悬停显示 `user@host:port` 悬浮提示。
- 溢出：横向滚动 + 右侧下拉列出全部标签。
- 快捷键提示在工具提示中展示。

### 3.4 终端区域

- 内边距 8px；光标始终可见。
- 选中即复制（可配置）；中键粘贴（桌面 Linux/Windows 习惯，默认关闭）。
- 右上角浮动按钮（悬停显示）：搜索、清屏、SFTP、复制全部输出。
- 断线覆盖层：半透明遮罩 + "连接已断开" + 原因 + [重连] [关闭]；重连倒计时可见。

### 3.5 分屏

- 布局：单栏、左右、上下、2×2（P1）。
- 拖拽分隔条调整比例；双击分隔条均分。
- 每个分屏独立标签组（P1）或共享标签栏（P0 默认共享）。

### 3.6 SFTP 视图

```
┌────────────────────────────────────────────────────────────────────┐
│ [本地: C:\Users\me ▾]  ⇄  [远程: /var/www ▾]   [刷新][上传][下载]  │
├──────────────────────────┬─────────────────────────────────────────┤
│ 名称        大小   修改   │ 名称           大小   权限   修改      │
│ ..                       │ ..                                      │
│ deploy/                  │ app/                                    │
│ logs/                    │ nginx.conf      2.1K  644    10-28      │
│ backup.tar.gz  1.2G      │                                         │
├──────────────────────────┴─────────────────────────────────────────┤
│ 传输队列 (2)  ▸ app.tar.gz  ███████░░░ 62%  12.4 MB/s  剩余 00:38  │
└────────────────────────────────────────────────────────────────────┘
```

- 双栏各占 50%，可拖动；窄窗口（< 900px）自动切换为单栏 + 切换按钮。
- 传输队列可折叠为 32px 状态条；失败项红点 + 重试按钮。
- 危险操作（删除目录、覆盖）使用模态确认，默认焦点在"取消"。

### 3.7 设置窗口

- 左侧导航：通用 / 外观 / 终端 / 快捷键 / 网络 / 同步 / 关于。
- 右侧表单，立即生效（无需"保存"），底部提供"恢复默认"。
- 修改同步类设置后显示"正在同步…"的轻提示。

### 3.8 命令面板（`Ctrl+Shift+P`）

- 模糊搜索所有动作：连接、切换主题、打开设置、立即同步、打开 SFTP、断开全部。
- 每项显示快捷键；危险动作标红。

### 3.9 同步与冲突 UI

| 状态 | 展示 |
|---|---|
| 未登录 | 状态栏灰色圆点 + "本地模式"，点击打开 Pro 介绍页 |
| 同步中 | 蓝色圆点 + 旋转图标，悬停显示待推送条数 |
| 已同步 | 绿色圆点 + "已同步 · 3 秒前" |
| 离线 | 橙色圆点 + "离线，N 条待同步" |
| 授权过期 | 橙色圆点 + 横幅"订阅已到期，同步暂停 [续费]" |
| 冲突 | 橙色圆点 + 数字徽标；点击打开冲突列表 |

冲突列表每项展示：记录名称、本机修改时间、云端修改时间、[保留本机] [保留云端] [另存副本]，支持"全部保留本机/全部保留云端"。

```

│ $ ls -la                │

## 8. 状态与反馈

| 状态 | 表现 |
|---|---|
| 空状态 | 插画 + 一句说明 + 主操作按钮；不使用空白页 |
| 加载中 | 骨架屏（列表）/ 进度指示（操作 > 300ms 才显示，避免闪烁） |
| 操作成功 | 轻提示（Toast）2 秒，不打断 |
| 可恢复错误 | 内联错误 + 重试按钮 |
| 不可恢复错误 | 模态 + 错误码 + "复制诊断信息" + 帮助链接 |
| 离线 | 顶部细横幅（非模态），显示待同步数量 |
| 首次使用 | 分步引导（创建连接 → 连接 → SFTP），可跳过 |

### 8.1 错误文案结构

> **发生了什么** + **可能原因** + **下一步动作**

示例：

- 连接超时："无法连接到 10.0.0.8:22（超时）。请检查网络、防火墙或主机是否在线。[重试] [编辑连接]"
- 认证失败："服务器拒绝了密钥认证。该密钥可能未添加到 authorized_keys，或需要口令。[重试] [编辑连接]"
- 主机指纹变更："主机密钥与上次记录不一致，可能存在中间人攻击。旧指纹：SHA256:abc… 新指纹：SHA256:def… [取消] [信任新密钥]"
- 同步冲突："「prod-web-01」在另一台设备被修改。[查看冲突]"

避免："出错了""未知错误""操作失败"。

## 9. 国际化

- 支持 `zh-CN`、`en-US`；默认跟随系统，可在设置中切换。
- 所有文案走 i18n key（`ui.connection.new`），禁止硬编码。
- 布局使用弹性尺寸，英文长文案不得截断关键操作。
- 时间显示相对格式（"3 分钟前"），悬停显示绝对时间。
- 数字与文件大小使用本地化格式（1.2 GB / 1.2 GB）。
- 终端编码默认 UTF-8，可切换 GBK/GB18030 以兼容旧系统。

---

## 10. 无障碍与可用性

- 全部可点击元素支持键盘聚焦，焦点环 2px `accent`。
- 提供高对比度主题（跟随系统）。
- 图标按钮必须有 `aria-label` / 可访问名称。
- 文本缩放至 200% 时布局不破。
- 动画可关闭；闪烁响铃符合"每秒不超过 3 次"。
- 终端内容不为屏幕阅读器逐字播报（性能原因），但提供"复制全部输出"与"导出"。

## 11. 视觉资产

- 应用图标：几何"贝壳 + 终端光标"隐喻，单色可识别，32–1024px 多尺寸。
- 平台图标：Windows `.ico`、macOS `.icns`、Android adaptive icon、iOS AppIcon。
- 插图：仅空状态使用，2 套（浅色/深色），线性风格，主色 `accent`。
- 终端主题：内置 6 套（One Dark、Dracula、Nord、Solarized Dark、Tokyo Night、Light），支持导入 iTerm/Windows Terminal 主题（P1）。
