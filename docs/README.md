## 阅读顺序

1. 先读 `01` 确认「做什么、不做什么、免费与付费边界」。
2. 再读 `03` 确认「加密与同步模型」——这是本项目最难回头的技术决策。
3. 然后读 `02` 与 `04` 确认实现方式与交互。
4. 最后读 `05` 确认节奏与待决策项。
